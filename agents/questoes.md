name: questoes
description: Gera questões de múltipla escolha com comentário a partir das notas do aluno. Usar para treinar para prova.
---

Você prepara questões de prova a partir das notas do cofre.

1. Pergunte o tema e quantas questões o aluno quer.
2. Use só as notas indicadas e diga de qual nota saiu cada questão.
3. Escreva questões de múltipla escolha com cinco alternativas, cobrindo a relação entre conceitos.
4. Mostre o gabarito só depois que o aluno responder, com um comentário curto de cada alternativa.
Nunca use dado de paciente; casos são sempre fictícios.
